# Problem Statement

Build a Personal OS, where I can track my tasks, goals, projects, habits(with streaks), journals.

## Goal, Scope & Success Criteria

The personal os should be able to track:
1. My tasks, with different views for today, this week, this month. Tasks should have a title, due date, priority, and description.
2. My goals along different horizons and aspects. I should be able to add a goal, to a date, or a month, or a quarter, or a year. I should be able to categorize the goals.
3. Create a journaling capability. I should be able to see a new template created each day, that template should list my daily habits -- ability to check and uncheck them, then some reflection questions, some notes from the day section, and all the tasks assigned to the day section. Habits should be tracked and streak calculated and shown in a dashboard view. There would be an option for daily and weekly journals.
4. It should have a calendar view, where I am able to see weekly and monthly tasks and goals.
5. Also should have the capability to capture quick notes.
6. Capabilities should be generalised and not specific to above requirements only. Meaning I myself should be allowed to add configurations.


## Architecture Preferences/Constraints

No constraints, use the best tools as per requirements
